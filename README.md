# PayPal Financial Performance Dashboard

A financial analysis dashboard built using real data from PayPal's SEC annual filings (2020–2024).

## What's inside
- Revenue vs Net Income (2020–2024)
- Net Profit Margin trend — including 2022 dip analysis
- Active Accounts vs Transactions Per Account (engagement insight)
- Total Payment Volume growth

## Key findings
- Revenue grew 48.3% from $21.5B (2020) to $31.8B (2024)
- 2022 margin dip to 8.8% reflects post-pandemic normalisation
- Active accounts plateaued but engagement per user grew 50%
- TPV grew 79.5% — volume outpacing user growth significantly
